# 분양·임대 공고 조회 기능

한국토지주택공사(LH)의 분양 및 임대 주택 공고 정보를 조회하는 기능입니다.

## 📋 기능 개요

- 한국토지주택공사의 분양·임대 공고 검색
- 날짜, 지역, 공고유형, 공고상태별 필터링
- 공고명 키워드 검색
- 페이지네이션 지원
- 공고 상세 페이지로 이동

## 🔑 API 키 발급 및 설정

### 1. API 키 발급

1. [공공데이터포털](https://www.data.go.kr/) 접속 및 회원가입/로그인
2. [한국토지주택공사_분양임대공고문 조회 서비스](https://www.data.go.kr/data/15058530/openapi.do) 페이지 접속
3. **활용신청** 버튼 클릭
4. 개발계정 또는 운영계정 신청
   - 개발계정: 즉시 승인 (트래픽 10,000/일)
   - 운영계정: 활용사례 등록 후 신청 가능
5. 신청 후 **마이페이지 > 오픈API > 개발계정 상세보기**에서 **일반 인증키(Decoding)** 확인

### 2. 환경변수 설정

`.env.local` 파일에 발급받은 API 키 추가:

```bash
# 한국토지주택공사 (LH) 분양임대 공고 API
LH_API_KEY=발급받은_인증키를_여기에_입력
```

**중요**: 
- **일반 인증키(Decoding)** 또는 **인코딩 인증키(Encoding)** 모두 사용 가능합니다.
- 서버에서 자동으로 인증키 형태를 감지하여 처리합니다.
- 공공데이터포털 마이페이지에서 두 가지 형태의 인증키를 모두 확인할 수 있습니다:
  - 일반 인증키 (Decoding): `ABC123def456...` 형태
  - 인코딩 인증키 (Encoding): `ABC%2B123%2Fdef...` 형태 (% 기호 포함)

## 📝 API 명세

### 요청 파라미터

#### 필수 파라미터
- `PAN_NT_ST_DT` (공고게시일): 형식 `YYYY.MM.DD` (예: 2024.01.01)
- `CLSG_DT` (공고마감일): 형식 `YYYY.MM.DD` (예: 2024.12.31)
- `PG_SZ` (페이지당 결과 수): 기본값 10
- `PAGE` (페이지 번호): 기본값 1

#### 선택 파라미터
- `PAN_NM` (공고명): 검색 키워드
- `UPP_AIS_TP_CD` (공고유형코드): 
  - 01(토지)
  - 05(분양주택)
  - 06(임대주택)
  - 13(주거복지)
  - 22(상가)
  - 39(신혼희망타운)
- `CNP_CD` (지역코드): 
  - 11(서울), 26(부산), 27(대구), 28(인천), 29(광주), 30(대전), 31(울산)
  - 36110(세종), 41(경기), 42(강원), 43(충북), 44(충남)
  - 52(전북), 46(전남), 47(경북), 48(경남), 50(제주)
- `PAN_SS` (공고상태): 공고중, 접수중, 접수마감, 상담요청, 정정공고중

### 응답 데이터

```typescript
{
  SS_CODE: 'Y',           // 성공 여부
  RS_DTTM: '20240101...',// 응답 시간
  ALL_CNT: '100',         // 전체 건수
  list: [
    {
      RNUM: '1',                    // 순번
      UPP_AIS_TP_NM: '임대주택',     // 공고유형명
      AIS_TP_CD_NM: '행복주택',      // 공고세부유형명
      PAN_NM: '행복도시 3-1M5...',   // 공고명
      CNP_CD_NM: '전국',            // 지역명
      PAN_SS: '공고중',             // 공고상태
      DTL_URL: 'https://...',       // 공고상세URL
      PAN_NT_ST_DT: '2024.01.01'   // 공고게시일 (선택)
    }
  ]
}
```

## 🎨 페이지 구성

### 검색 폼
- **공고게시일** (필수): 시작일 선택
- **공고마감일** (필수): 종료일 선택
- **공고명 검색**: 키워드 입력
- **공고유형**: 전체, 분양주택, 임대주택
- **지역**: 시도 선택
- **공고상태**: 전체, 공고중, 공고마감

### 결과 표시
- 공고 목록 카드 형태로 표시
- 공고유형, 공고세부유형, 공고상태 뱃지
- 공고명, 지역, 공고게시일 표시
- 클릭 시 공고 상세 페이지로 이동 (새 탭)
- 페이지네이션 지원

## 🚀 사용 방법

### 1. 개발 서버 실행

```bash
npm run dev
```

### 2. 분양·임대 공고 페이지 접속

브라우저에서 `http://localhost:3000/lease` 접속

### 3. 검색 수행

1. 공고게시일과 공고마감일 선택 (필수)
2. 필요시 추가 필터 설정
3. 검색 버튼 클릭
4. 결과 확인 및 공고 클릭하여 상세 정보 확인

## 🔧 트러블슈팅

### API 키 관련 오류

**문제**: "API 키가 설정되지 않았습니다." 오류
- **해결**: `.env.local` 파일에 `LH_API_KEY` 환경변수가 올바르게 설정되었는지 확인
- 서버를 재시작해야 환경변수가 적용됩니다.

**문제**: "SERVICE_KEY_IS_NOT_REGISTERED_ERROR" 오류
- **해결**: 
  1. 공공데이터포털에서 API 활용신청이 승인되었는지 확인
  2. 일반 인증키(Decoding) 값을 사용하고 있는지 확인
  3. 인증키를 복사할 때 공백이 포함되지 않았는지 확인

### 검색 결과 없음

**문제**: 검색 조건에 맞는 결과가 없음
- **해결**: 
  1. 날짜 범위를 넓혀서 검색
  2. 필터 조건을 줄여서 검색
  3. 공고명 키워드를 변경하거나 제거

### 응답 속도 느림

**문제**: API 응답이 느림
- **해결**: 
  1. 날짜 범위를 좁혀서 검색
  2. 페이지당 결과 수를 줄이기
  3. 네트워크 상태 확인
