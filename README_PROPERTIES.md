# 경매 물건 상세 정보 기능

## 🎉 새로운 기능

서울과 경기 지역의 경매 물건 상세 정보를 크롤링하여 제공합니다!

### ✨ 제공 정보

#### 기본 정보
- ✅ **정확한 주소** (도로명주소)
- ✅ **사건번호** 및 법원명
- ✅ **물건 종류** (아파트, 연립/다세대, 단독주택, 토지, 상가 등)
- ✅ **건축년도**
- ✅ **진행상태**

#### 면적 정보
- ✅ **전용면적** (㎡ / 평)
- ✅ **공급면적** (㎡ / 평)

#### 가격 정보
- ✅ **감정가**
- ✅ **최저입찰가**
- ✅ **입찰일시**
- ✅ **입찰횟수**

#### 단지 정보 (아파트)
- ✅ **아파트명/단지명**
- ✅ **총 세대수**
- ✅ **동수**

#### 시설 및 입지
- ✅ **부대시설** (엘리베이터, 주차장 등)
- ✅ **주변 환경 설명**
- ✅ **교통 정보**

#### 추가 정보
- ✅ **물건 사진** (이미지 갤러리)
- ✅ **법원경매정보 사이트 링크**

## 📱 페이지 구조

```
메인 페이지 (/)
  ├─ 통계 조회 (기존 기능)
  └─ 경매 물건 검색 링크
  
경매 물건 검색 (/properties)
  ├─ 검색 조건 입력
  ├─ 검색 결과 목록 (카드형)
  └─ 상세 페이지 링크
  
경매 물건 상세 (/properties/[사건번호])
  ├─ 기본 정보
  ├─ 면적 정보
  ├─ 단지 정보
  ├─ 부대시설
  ├─ 입지 정보
  ├─ 물건 사진
  └─ 가격 정보 (사이드바)
```

## 🔍 검색 조건

### 지역 필터
- 시도: 서울특별시, 경기도
- 시군구: 각 시도별 하위 지역

### 물건 필터
- 물건 종류: 아파트, 연립/다세대, 단독주택, 토지, 상가
- 가격 범위: 최소~최대 (만원 단위)
- 면적 범위: 최소~최대 (㎡)

## 🛠️ 기술 구현

### 크롤링
- **라이브러리**: Playwright
- **대상 사이트**: 법원경매정보 (https://www.courtauction.go.kr/)
- **방식**: Headless browser + HTML 파싱
- **제한**: 서울/경기 지역만 크롤링

### API 엔드포인트

#### 1. 경매 물건 검색
```
GET /api/auction/search
```

**파라미터**:
- `region`: 지역 (서울특별시, 경기도)
- `district`: 시군구
- `buildingType`: 물건종류
- `minPrice`: 최소가격 (원)
- `maxPrice`: 최대가격 (원)
- `minArea`: 최소면적 (㎡)
- `maxArea`: 최대면적 (㎡)

**응답 예시**:
```json
{
  "success": true,
  "properties": [
    {
      "caseNumber": "2024타경12345",
      "courtName": "서울중앙지방법원",
      "address": "서울특별시 강남구 테헤란로 123",
      "buildingType": "아파트",
      "appraisalValue": 500000000,
      "minimumBidPrice": 400000000,
      "bidDate": "2024-03-15 14:00"
    }
  ],
  "total": 42,
  "page": 1,
  "totalPages": 3
}
```

## ⚠️ 주의사항

### 크롤링 제한
1. **Rate Limiting**: 과도한 요청 방지를 위해 적절한 지연 시간 적용
2. **Timeout**: 각 요청 최대 30초
3. **Headless Mode**: 서버 리소스 절약

### 법률적 고려사항
1. ✅ **공개 정보만 수집**: 법원경매정보 사이트의 공개 정보만 크롤링
2. ✅ **개인정보 제외**: 개인정보는 수집하지 않음
3. ✅ **robots.txt 준수**: 크롤링 정책 준수
4. ✅ **출처 표시**: 법원경매정보 사이트 링크 제공

### 성능 최적화
- **캐싱**: 동일한 물건 정보는 일정 시간 캐싱 (선택적 구현)
- **비동기 처리**: 크롤링 작업은 비동기로 처리
- **에러 핸들링**: 크롤링 실패 시 적절한 에러 메시지 표시

## 🚀 사용 방법

### 1. 통계 조회에서 시작
- 메인 페이지에서 날짜별/지역별 경매 건수 확인

### 2. 상세 정보 검색
- "경매 물건 검색" 버튼 클릭
- 원하는 조건 입력 (지역, 가격, 면적 등)
- 검색 버튼 클릭

### 3. 목록에서 선택
- 검색 결과 카드 클릭
- 각 물건의 기본 정보 확인

### 4. 상세 정보 보기
- 건축년도, 평수, 단지 정보 등 상세 정보 확인
- 입지, 교통 정보 확인
- 물건 사진 갤러리 확인
- 가격 정보 및 입찰 일정 확인

### 5. 법원경매정보 사이트 이동
- 더 자세한 정보는 "법원경매정보에서 보기" 버튼 클릭

## 🔧 트러블슈팅

### 크롤링 실패 시
- 네트워크 연결 확인
- 법원경매정보 사이트 접속 가능 여부 확인
- 브라우저 콘솔(F12)에서 에러 메시지 확인

### 검색 결과 없음
- 검색 조건을 완화해보세요
- 지역을 "전체"로 변경
- 가격 범위를 넓혀보세요

### 상세 정보 로딩 느림
- 크롤링 작업은 30초~1분 정도 소요될 수 있습니다
- 인내심을 가지고 기다려주세요
